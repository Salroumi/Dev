# منظّف الرسائل (SMS Cleaner) — تطبيق أندرويد

تطبيق يراجع رسائل SMS الواردة على جهازك، ويصنّفها ويتحقق منها، ثم **يقترح** حذف الرسائل غير الضرورية.
**لا يُحذف أي شيء قبل تأكيدك**، وكل الفحص يتم على الجهاز فقط (لا يوجد إنترنت ولا إرسال بيانات).

## ماذا يفحص؟

| التصنيف | الإجراء المقترح | مثال |
|---|---|---|
| مشبوهة / احتيال | حذف + تحذير | روابط مختصرة (bit.ly)، نطاقات مشبوهة (.xyz)، «تم إيقاف حسابك»، «ربحت جائزة»، رقم شخصي يدّعي أنه بنك |
| مكررة | حذف (يبقى الأحدث) | نفس النص من نفس المرسل |
| رمز تحقق منتهي | حذف | رمز OTP عمره أكثر من 24 ساعة |
| إعلانية | حذف | عروض، خصومات، «لفترة محدودة»، 50% |
| رمز تحقق حديث | إبقاء | OTP عمره أقل من 24 ساعة |
| معاملة بنكية | إبقاء | شراء، رصيد، حوالة، مبلغ |
| شخصية | إبقاء | مرسل موجود في جهات الاتصال |
| أخرى | إبقاء | تُراجع يدويًا |

يمكنك تعديل التحديد قبل الحذف (تحديد/إلغاء أي رسالة، أو تصفية حسب التصنيف)، ثم يظهر مربع تأكيد بعدد الرسائل وتوزيعها قبل الحذف النهائي.

## العمليات المالية

تبويب «العمليات المالية» يقرأ رسائل البنوك والمحافظ ويستخرج من كل رسالة:

- **نوع العملية:** شراء، سحب نقدي، حوالة صادرة/واردة، سداد فاتورة، راتب، إيداع، استرداد، رسوم بنكية، عملية مرفوضة
- **المبلغ والعملة** (يدعم الأرقام العربية، و«ر.س» و SAR و USD وغيرها) و**الرصيد** بعد العملية
- **التاجر أو الطرف الآخر** وآخر 4 أرقام من البطاقة/الحساب
- **فئة الصرف:** مطاعم ومقاهي، بقالة، وقود، مواصلات، تسوق، فواتير واتصالات، صحة، اشتراكات، سفر، خدمات حكومية…

ويعرض ملخصًا لكل شهر: الدخل، المصروفات، الصافي، وتوزيع المصروفات حسب الفئة (اضغط على فئة لعرض عملياتها).
رسائل رموز التحقق للعمليات والإعلانات التي تذكر مبالغ **لا** تُحسب كعمليات، والعمليات المرفوضة تظهر لكنها لا تدخل في المجموع.

## ملاحظة مهمة عن الحذف

نظام أندرويد (منذ 4.4) **لا يسمح بحذف الرسائل إلا لتطبيق الرسائل الافتراضي**. لذلك عند الضغط على «حذف» يطلب التطبيق تعيينه كافتراضي **مؤقتًا**، وبعد الحذف تظهر بطاقة لإرجاع تطبيق الرسائل المعتاد.
أثناء كونه افتراضيًا يستقبل التطبيق الرسائل النصية ويحفظها ويُظهر إشعارًا، لكنه لا يستقبل رسائل الوسائط (MMS)، لذا يُنصح بإرجاع التطبيق المعتاد بعد التنظيف.

## التثبيت

- **من GitHub Actions:** كل دفعة (push) تبني ملف APK. افتح تبويب *Actions* ← آخر تشغيل لـ *Android build* ← حمّل `sms-cleaner-apk`، ثم ثبّته على الجوال (مع السماح بالتثبيت من مصادر غير معروفة).
- **محليًا:** افتح المشروع في Android Studio أو نفّذ:
  ```bash
  ./gradlew assembleDebug        # الناتج: app/build/outputs/apk/debug/app-debug.apk
  ./gradlew testDebugUnitTest    # اختبارات محرك التصنيف
  ```

المتطلبات: أندرويد 6.0 (API 23) فأعلى.
